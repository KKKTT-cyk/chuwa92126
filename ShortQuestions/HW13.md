1.A static nested class has no hidden reference to its outer object. An inner class does, so a long-lived inner object can keep the outer object in memory and cause a leak. Prefer static nested classes unless outer-instance access is needed.
2.Java uses type erasure: generic type arguments are checked at compile time, then removed. T is erased to its bound (usually Object), so new T() cannot instantiate an unknown type, new T[10] cannot create an array with an unknown runtime component type, and instanceof List<String> cannot check a type argument that no longer exists at runtime. The compiler generates a bridge method when erasure changes an overriding method’s signature, preserving polymorphic calls.
3.PECS means Producer Extends, Consumer Super.
- List<? extends Number> produces Number values, so you can read them as Number. You cannot safely add a Number because the list’s actual element type might be Integer or Double.
- List<? super Integer> can consume Integer values, so you can add an Integer. When reading, the safe type is only Object.
  Generics are invariant: List<Integer> is not a subtype of List<Number>, which prevents adding (for example) a Double to a list of integers. Arrays are covariant: Integer[] is a subtype of Number[]; an incompatible store is caught at runtime with ArrayStoreException.
4.- SOURCE: discarded by the compiler.
- CLASS: stored in the .class file, but not available through runtime reflection.
- RUNTIME: stored and available through reflection.
- @Target restricts where an annotation can be used.
- @Inherited lets a class inherit an annotation from its superclass.
- @Repeatable allows the same annotation to appear multiple times.
  For runtime reflection, an annotation must use RetentionPolicy.RUNTIME.
5.You can obtain a Class object with TypeName.class, object.getClass(), Class.forName("fully.qualified.Name"), or classLoader.loadClass("fully.qualified.Name").

setAccessible(true) asks reflection to bypass Java access checks. The module system can block this for packages that are not open to the caller’s module. Method.invoke wraps an exception thrown by the target method in InvocationTargetException, so it can distinguish the target’s failure from reflection errors; use getCause() to inspect the original exception.
