## 1. 什么是 ORM?
ORM helps mapping java objects to database data, which helps developers to work with object with framework, and do not need to write sql directly. A Java class usually maps to a database table, an object represents a row, and a field maps to a column.

## 2. JPA 和 Hibernate 有什么区别?
JPA is a standard rules that define how to map java objects to database tables. Hibernate is a framework that implement JPA, which do the real work to generate SQL, access database, and convert objects.

## 3. Spring Data JPA 解决了什么问题?
Spring data JPA reduce repetitive code from repository like CRUD operations by offering the interface for normal implementations.
For example, extending JpaRepository provides methods such as findById(), save(), and deleteById() without writing their method bodies. The underlying JPA provider, such as Hibernate, still handles the database operations.

## 4. 什么是 Entity?
Entity is a annotaion in java helps to identify and map the tables to the corresponding object.

## 5. 为什么 Entity 需要 primary key?
An entity needs a primary key to uniquely identify its database row. Other fields may contain duplicate values, JPA uses the primary key to distinguish entities and locate the correct row when finding, updating, or deleting data.



## 6. 为什么 Student 和 Course 之间需要 Enrollment?
An Enrollment represents one student enrolling in one course. It connects Student and Course in their many-to-many relationship: a student can take many courses, and a course can have many students.

It also stores details about that specific enrollment, such as the enrollment date, status, and grade. These details belong to the student–course relationship, rather than to the student or course alone.

## 7. 什么是 owning side?
The owning side is the side of a relationship that JPA uses to save relationship changes to the database. Changes on this side determine updates to the foreign key or join table.

## 8. `mappedBy = "student"` 表示什么?
mappedBy = "student" tells JPA that the relationship is managed by the student field in the related entity. "student" is a Java field name, not the database column name student_id.




## 9. LAZY 和 EAGER 有什么区别?
LAZY requests that related data be loaded only when needed. For example, loading an Enrollment may leave its Course unloaded; accessing the course title can trigger another query.

EAGER requires related data to be loaded when the entity is retrieved, even if the application never uses it. This may use a join or additional SQL queries—EAGER does not guarantee a single query.


## 10. 一次请求是如何到达 database 的?
An HTTP request reaches the Controller, which calls the Service to handle business logic. The Service then calls a Repository to access data.

Spring Data JPA provides the repository implementation and uses JPA APIs backed by Hibernate. Hibernate prepares SQL and executes it through JDBC and the database driver. The database processes the SQL and returns results.

Hibernate maps the results into Java objects. These return through the Repository and Service to the Controller, where Spring converts the response into JSON.
