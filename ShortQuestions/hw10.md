1. Kafka is a distributed event-streaming platform for storing and exchanging messages. It is commonly used to decouple services, support asynchronous communication, and build real-time data pipelines.
2. A message (record) is a unit of data in Kafka. It typically contains a value (payload), an optional key, a timestamp, and optional headers for metadata.
3. A Producer is a client application that creates and sends messages to Kafka topics. For example, a shopping app sends an “order created” message when a customer places an order. kafka.apache.org
4. A Consumer is a client application that reads and processes messages from Kafka topics. For example, an inventory service reads an “order created” message and updates the stock
5. A Topic is a named category of messages, such as orders or payments. It organizes messages so producers know where to send them and consumers can subscribe to the data they need.
6. A Broker is a Kafka server that stores messages and handles producer and consumer requests. Multiple Brokers distribute the workload, increase storage capacity, and support fault tolerance through data replication.
7. A Partition is an ordered sequence of messages within a Topic. Multiple Partitions allow data to be spread across Brokers and processed in parallel, improving scalability and throughput. kafka.apache.org
8. An Offset identifies a message’s position within a specific Partition. It is not a global message ID: Partition 0 and Partition 1 can both have a message with Offset 5.
9. A Consumer Group is a set of Consumers that work together to consume messages. Each Partition is assigned to only one Consumer in the group at a time, while one Consumer may handle multiple Partitions.
10. A Key is an optional identifier attached to a message, such as a customer ID. By default, Kafka’s Producer hashes the Key to select a Partition, so messages with the same Key go to the same Partition, provided the partition count stays unchanged.
11. A Topic is a logical category of messages, divided into one or more Partitions that store those messages and enable parallel processing.
12. A Broker is a single Kafka server. A Kafka cluster contains one or more Brokers working together, so one Broker can form a single-Broker cluster, but a cluster often has multiple Brokers.
