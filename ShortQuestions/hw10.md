# Kafka Homework


1. 什么是 Kafka？它通常⽤来解决什么问题？

Kafka is a distributed event streaming platform used to send, store, and process real-time data. It helps different applications communicate without directly depending on each other. Kafka is used to handle large amounts of data and build scalable, event-driven systems.


2. 什么是消息（Message/Record）？⼀条 Kafka 消息通常可以包含哪些信息？

Message is a unit of data sent from a producer to Kafka. A Kafka message usually contains a value and may also include a key, timestamp, and headers. After being stored in Kafka, it is associated with a partition and an offset.


3. 什么是⽣产者（Producer）？它在 Kafka 中承担什么职责？

Producer is an application that sends messages to Kafka topics. It is responsible for creating and publishing messages and can specify a message key to help determine which partition the message is sent to.


4. 什么是消费者（Consumer）？它在 Kafka 中承担什么职责？

Consumer is an application that reads messages from Kafka topics and processes them, and it can subscribe to topics and retrieve messages at their own pace.


5. 什么是主题（Topic）？为什么 Kafka 要使⽤ Topic 对消息进⾏分类？

Topic is a logical category used to organize related messages in Kafka, helping separate different types of data, such as orders, payments, and notifications. This allows consumers to subscribe to the specific data they need.


6. 什么是 Broker？Kafka 集群中为什么可以有多个 Broker？

Broker is a Kafka server that stores messages and handles requests from producers and consumers. A Kafka can have multiple brokers to distribute data, improve scalability, and provide fault tolerance.


7. 什么是分区（Partition）？⼀个 Topic 为什么可能需要多个 Partition？

Partition is a smaller part of a Kafka topic that stores messages in order. A topic can have multiple partitions to distribute data across brokers and allow consumers to process messages in parallel, improving scalability and performance.


8. 什么是 Offset？它表示的是消息的全局编号，还是消息在某个 Partition 中的位置？

Offset is a number that identifies the position of a message within a specific partition and each partition has its own offsets starting from 0. Offset is not global message ID.


9. 什么是消费者组（Consumer Group）？同⼀个消费者组中的多个消费者如何分⼯？

Consumer group is a group of consumers working together to process messages from a topic. Kafka distributes partitions among consumers in the same group and each partition is assigned to only one consumer within the group at a time.


10. 什么是消息键（Key）？Key 会如何影响消息被写⼊哪个 Partition？

Message key is a value used to determine which partition a message is sent to. Kafka uses hashing to assign messages with the same key to the same partition to maintain their order.


11. Topic 和 Partition 有什么区别？请⽤⼀句话描述它们之间的关系。

Topic is a logical category for messages, while partition is a part of a topic that stores messages in order and allows parallel processing.


12. Broker 和 Kafka 集群有什么区别？⼀个 Broker 是否就等于⼀个 Kafka 集群？

Broker is a single Kafka server, while Kafka cluster is a group of one or more brokers working together. Multiple brokers are commonly used for scalability and fault tolerance.


13. Producer 和 Consumer 是否需要彼此知道对⽅是谁？请说明原因。

Producers and consumers do not need to know each other, because producers send messages to Kafka topics, and consumers read messages from those topics independently.


14. Offset 是由 Producer 决定的吗？消费者为什么需要记录⾃⼰的消费位置？

Offset is assigned by Kafka when messages are written to a partition. Consumers track and commit their offsets to remember their progress, so they can resume processing from the last position after a restart or failure.


15. “Kafka 能保证整个 Topic 中的所有消息严格有序。”这句话是否正确？请说明 Kafka 的顺序保证范围。

The statement is incorrect. Kafka only guarantees message ordering within each partition, not the entire topic. Messages in the same partition are stored in order, but messages across different partitions may be consumed in different orders.


16. 如果⼀个 Topic 有 3 个 Partition，同⼀个消费者组中有 5 个 Consumer，那么最多有⼏个 Consumer 能同时消费这个Topic？其余 Consumer 会怎样？

At most 3 consumers can actively consume messages because each partition can only be assigned to one consumer within the same group. The other 2 consumers will remain idle until partitions are reassigned.


17. 两个不同的消费者组订阅同⼀个 Topic，它们会互相抢消息吗？请解释它们各⾃能看到哪些消息。

Different consumer groups do not compete for messages. Each group can independently consume messages from the same topic and maintain its own offsets, allowing different applications to process the same messages without affecting each other.
