1. A static nested class does not require an enclosing instance and cannot directly access its instance members. 
An inner class requires an enclosing instance and normally holds a hidden reference to it, accessible as Outer.this.
If the inner object outlives the outer object, this reference can prevent the outer object from being garbage-collected.
A static nested class is usually preferred when access to an enclosing instance is unnecessary because it avoids this 
implicit reference and reduces coupling.
2. Type erasure replaces type parameters with their bounds, or Object if unbounded. For List<String>, the runtime type 
is List; the compiler checks types and inserts casts where needed.
new T() is illegal because the concrete type and constructor are unknown.
new T[10] is illegal because arrays require a runtime component type, while T is erased.
obj instanceof List<String> is illegal because runtime checks cannot distinguish List<String> from other parameterization. 
Use instanceof List<?>.
A bridge method is a synthetic method generated by the compiler to preserve overriding and polymorphism after erasure. 
For example, it may generate set(Object) to delegate to an overriding set(String).
3. PECS means Producer Extends, Consumer Super.
   | Type                   | Reading                 | Adding |
   | List<? extends Number> | Read safely as Number | Cannot add a non-null value because the actual element type is unknown |
   | List<? super Integer>  | Read safely only as Object | Can add Integer values because the actual element type is Integer or a supertype |
Generics are invariant: List<Integer> is not a subtype of List<Number>, preventing unsafe insertions.
Arrays are covariant: Integer[] is a subtype of Number[]. Arrays retain their component type at runtime and reject 
incompatible values with ArrayStoreException.
4. SOURCE: Available in source code only; discarded during compilation.
   CLASS: Stored in class files but unavailable through runtime reflection. This is the default.
   RUNTIME: Stored in class files and available through runtime reflection.
   @Target: Specifies where an annotation can be applied.
   @Inherited: Allows a class annotation to be inherited through the superclass hierarchy; it does not apply to 
   interfaces or overridden methods.
   @Repeatable: Allows the same annotation type to appear multiple times on one element, using a container annotation.
5. Common ways to obtain a Class object include:
   String.class;
   obj.getClass();
   Class.forName("java.lang.String");
   classLoader.loadClass("java.lang.String");
setAccessible(true) requests suppression of Java language access checks, allowing access to otherwise inaccessible 
members when permitted.
The module system restricts this: deep reflection into another module’s non-public members generally requires the 
package to be opened, for example with opens or --add-opens. Otherwise, access can fail with InaccessibleObjectException.
Method.invoke() wraps an exception thrown by the target method in InvocationTargetException, distinguishing a target 
failure from reflection-related failures. Retrieve the original exception with getCause().
