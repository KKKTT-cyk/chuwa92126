## Question 1
The histogram produces 11 time series per label combination: 8 finite buckets, 1 +Inf bucket, 1 sum, and 1 count. With 100 instances, 20 endpoints, and 4 status values, the total is 100 × 20 × 4 × 11 = 88,000 series. Adding 50,000 distinct user_id values raises the worst-case total to 88,000 × 50,000 = 4.4 billion.

More series require more memory to track active series, more space for indexes and samples, and more processing during ingestion and queries. Three techniques to keep cardinality:
1. Leave user_id out of metric labels.
2. Aggregate histogram data across unwanted label values before sending it to storage.
3. Set an active-series limit for each tenant to protect the shared database.


## Question 2
The combined p99 is the 990th latency after sorting all 1,000 requests. Each local p99 gives only one point in its distribution, so even a weighted average cannot recover the combined p99.
- Summaries estimate p99 locally and use one series per quantile, and the quantiles cannot be merged.
- Fixed-bucket histograms merge by adding matching bucket counts. Narrower buckets improve accuracy but create more series.
- Sketches merge compact distribution estimates. Their accuracy and memory use depend on their settings.
  
A bucket boundary at the latency objective lets us count how many requests meet the target. Narrower buckets around that boundary improve percentile estimates near the target.


## Quesiton 3
A 20-second window holds 2000 × 20 = 40000 traces. At 8 spans per trace and 400 bytes per span, the sampler tier needs 40000 × 8 × 400 = 128000000 bytes (128 MB) for span data, plus runtime overhead.

All spans with the same trace ID must go to the same sampler so it can see the full trace and make one sampling decision. When scaling from 4 to 5 nodes, modulo routing moves about 80% of traces because changing the divisor changes most assignments. Balanced consistent hashing moves about 20% because only the traces assigned to the new node need to move.


## Question 4
- 00 is version, 1 byte. It identifies the header format.
- 4bf92f3577b34da6a3ce929d0e0e4736 is trace ID, 16 bytes. It identifies the entire trace.
- 00f067aa0ba902b7 is Parent ID, 8 bytes. It identifies the upstream span that sent the request.
- 00 is trace flags, 1 byte. The sampled bit is unset.

With parent-based sampling, the service honors the upstream decision to leave the trace unsampled, forwards the unset sampled bit to the next service, and sets `parent-id` to the ID of its outgoing client span.


## Question 5
A 99.95% availability target allows 0.05% downtime. Over 30 days, that is 30 × 24 × 60 × 0.0005 = 21.6 minutes.

14.4× burn rate over 1 hour: The error threshold is 14.4 × 0.05% = 0.72%. This uses 14.4 × 1 / 720 = 2% of the budget. Page the on-call engineer.

6× burn rate over 6 hours: The error threshold is 6 × 0.05% = 0.30%. This uses 6 × 6 / 720 = 5% of the budget. Create a ticket. At this rate, the full budget runs out in 30 / 6 = 5 days.

The alert fires when both windows exceed the threshold. The long window filters out brief spikes, and the short window confirms the issue is still happening so the alert clears quickly after recovery.


## Question 6
The application exports telemetry asynchronously through a bounded queue, so requests can continue during a backend outage. If the queue fills up, the application drops telemetry to keep serving requests. Agents and collectors can buffer and retry during short outages, which uses memory or disk space. They can also sample traces to reduce volume, though some events may be missed. The backend can rate-limit each tenant to prevent overload, which may delay delivery or cause data loss.

At-least-once delivery retries when an acknowledgment is missing, so the backend may receive duplicates. At-most-once delivery sends each item at most once, so a failed send can result in data loss.

Alerting should run in a separate failure domain so it can still notify people when the monitored system goes down. A watchdog sends a regular heartbeat to an independent receiver. If the heartbeat stops arriving, the receiver can alert someone that the alerting path may have failed.
