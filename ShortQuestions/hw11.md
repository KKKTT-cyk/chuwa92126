# HW11 - Kafka Homework

## 1. 什么是 Kafka？它通常用来解决什么问题？

Answer:
Kafka is a platform for storing and sharing messages between applications.

It lets applications communicate without contacting each other directly. It also allows new data, such as GPS locations, to be passed to other applications as it is produced.

## 2. 什么是消息（Message/Record）？一条 Kafka 消息通常可以包含哪些信息？

Answer:
A message (record) is a piece of data sent through Kafka, such as “Order 1001 has been paid.”

It can contain a value, an optional key, a timestamp, and optional headers. Once stored, it also has a partition and an offset that identify its location.


## 3. 什么是生产者（Producer）？它在 Kafka 中承担什么职责？

Answer:
A producer is an application that sends messages to Kafka.

For example, an order service sends an “Order paid” message to Kafka after a payment succeeds.


## 4. 什么是消费者（Consumer）？它在 Kafka 中承担什么职责？

Answer:
A consumer is an application that reads messages from Kafka and processes them.

For example, a warehouse service reads an “Order paid” message and arranges shipping.

## 5. 什么是主题（Topic）？为什么 Kafka 要使用 Topic 对消息进行分类？

Answer:
A topic is a named category of messages in Kafka.

For example, an “orders” topic stores order messages. Topics organize messages so consumers can read the categories they need.

## 6. 什么是 Broker？Kafka 集群中为什么可以有多个 Broker？

Answer:
A broker is a Kafka server that stores messages and handles read and write requests.

A Kafka cluster can have multiple brokers to share the workload, store more data, and keep copies of data in case a broker fails.

## 7. 什么是分区（Partition）？一个 Topic 为什么可能需要多个 Partition？

Answer:
A partition is one part of a topic that stores a sequence of messages.

Multiple partitions let Kafka spread data across brokers and let consumers in the same group process different partitions at the same time.


## 8. 什么是 Offset？它表示的是消息的全局编号，还是消息在某个 Partition 中的位置？

Answer:
An offset is a message’s position within a partition, starting from 0.

It is not a global message ID. Different partitions can have the same offset for different messages.


## 9. 什么是消费者组（Consumer Group）？同一个消费者组中的多个消费者如何分工？

Answer:
A consumer group is a group of consumers that share the work of reading and processing messages.

Each partition is assigned to only one consumer in the group at a time. One consumer can handle multiple partitions.


## 10. 什么是消息键（Key）？Key 会如何影响消息被写入哪个 Partition？

Answer:
A key is an optional label on a message, such as an order ID. Kafka uses it to help choose a partition.

With normal key-based routing, messages with the same key go to the same partition as long as the partition count stays the same. Different keys can also go to the same partition.


## 11. Topic 和 Partition 有什么区别？请用一句话描述它们之间的关系。

Answer:
A topic groups related messages, such as order messages, and its one or more partitions each store some of those messages.

## 12. Broker 和 Kafka 集群有什么区别？一个 Broker 是否就等于一个 Kafka 集群？

Answer:
A broker is one Kafka server. A Kafka cluster is one or more brokers working together.

A broker is not necessarily the whole cluster, but a cluster can contain only one broker.


## 13. Producer 和 Consumer 是否需要彼此知道对方是谁？请说明原因。

Answer:
No. Producers send messages to Kafka topics, and consumers read messages from those topics.

They communicate through Kafka, so they do not need to know or contact each other directly.

## 14. Offset 是由 Producer 决定的吗？消费者为什么需要记录自己的消费位置？

Answer:
No. The broker assigns the offset when it stores a message in a partition.

Consumers save their progress so they know where to continue after a restart. For example, after processing offsets 0 and 1, they commit offset 2 as the next position to read.


## 15. “Kafka 能保证整个 Topic 中的所有消息严格有序。”这句话是否正确？请说明 Kafka 的顺序保证范围。

Answer:
No. Kafka guarantees message order only within each partition, based on the order messages are written.

It does not guarantee a single order across different partitions in a topic.

## 16. 如果一个 Topic 有 3 个 Partition，同一个消费者组中有 5 个 Consumer，那么最多有几个 Consumer 能同时消费这个 Topic？其余 Consumer 会怎样？

Answer:
At most 3 consumers can consume this topic at the same time because it has only 3 partitions.

The other 2 consumers remain idle. They may take over partitions if an active consumer leaves the group.

## 17. 两个不同的消费者组订阅同一个 Topic，它们会互相抢消息吗？请解释它们各自能看到哪些消息。

Answer:
No. Different consumer groups read messages independently and track their own progress.

Both groups can read all messages still retained in the topic, depending on their starting offsets. Reading a message in one group does not prevent another group from reading it.
